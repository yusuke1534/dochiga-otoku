どっちがお得？ Webアプリ

使い方：index.html をブラウザで開きます。
公開方法：ZIPを解凍し、中の4ファイルをGitHub Pages用リポジトリのルートにアップロードしてください。Settings → Pages → Deploy from a branch → main / root を選ぶと公開できます。
iPhone：公開URLをSafariで開く → 共有 → ホーム画面に追加。
機能：2～8商品比較、単位換算、入り数、履歴（localStorage）、オフライン動作（公開後に一度読み込んだ場合）。
注意：Webアプリのため、公開URLはユーザー自身のGitHub Pagesなどで設定する必要があります。
